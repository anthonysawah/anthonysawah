## Selected work here

- [gpu-node-guardian](https://github.com/anthonysawah/gpu-node-guardian):
  Kubernetes controller that watches NVIDIA DCGM metrics and cordons GPU
  nodes before failing hardware takes new pods.
- [ngx-platform-bedrock](https://github.com/anthonysawah/ngx-platform-bedrock):
  plain-English prompts become Aurora Serverless load tests via Bedrock,
  with live scaling charts and near-zero idle cost. Live demo linked in the repo.
- [gpu-cluster-toolkit](https://github.com/anthonysawah/gpu-cluster-toolkit):
  GPU cluster reliability tooling: the guardian controller plus a parallel
  validator that finds straggler nodes across a fleet.
- [espn-fantasy-baseball-api](https://github.com/anthonysawah/espn-fantasy-baseball-api):
  typed Python client for the ESPN Fantasy Baseball API, published on PyPI.
